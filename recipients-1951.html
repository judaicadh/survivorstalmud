The 1951 recipients

In 1951 the American Jewish Joint Distribution Committee recorded, under the heading “Re: Full set of Shas,” the institutions and individuals who received a complete set of the Survivors’ Talmud. This is that list — the starting point for tracing where each set is today. Where a set has already been located, its status is noted.
